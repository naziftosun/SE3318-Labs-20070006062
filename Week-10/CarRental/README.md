# Lab Week-10: Car Rental System

Hello! This is my lab project for Week 10. It's a simple car rental program.

## What Does This Program Do?
- Shows available cars (Economy and Luxury cars)
- Calculates rental prices
- Creates rental records

## My Files
- Main.java: The main program
- Model folder:
  - EconomyVehicle.java: For normal cars
  - LuxuryVehicle.java: For luxury cars
  - RentalRecord.java: For rental information

## How to Run
1. Open project in IntelliJ
2. Run Main.java
3. You will see the list of cars and rental information
